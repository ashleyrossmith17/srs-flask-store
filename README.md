# Самостоятельные работы №1 и №2 — GLOW ROOM

Учебное Flask-приложение с каталогом косметики. Реализованы маршруты, GET-фильтрация, динамическая карточка товара, POST-форма отзыва, серверная валидация, Jinja-шаблоны и адаптивное оформление.

## Запуск

```powershell
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
